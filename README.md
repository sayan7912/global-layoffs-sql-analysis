# Global Layoffs Data Analysis Using SQL

## 📌 Project Overview
Performed exploratory data analysis on a global layoffs dataset using SQL to identify trends, patterns, and business insights related to workforce reductions across companies, industries, countries, and funding stages.

## 🎯 Objectives
- Analyze layoff trends across different companies and industries.
- Identify countries most affected by layoffs.
- Examine monthly and yearly layoff patterns.
- Investigate the impact of funding stages on layoffs.
- Generate business insights through SQL-based analysis.

## 🛠️ Tools & Technologies
- MySQL
- SQL
- GitHub

## 🧹 Data Cleaning
- Removed duplicate records
- Standardized text fields
- Handled missing values
- Formatted date columns
- Corrected inconsistent data entries

## 📊 Exploratory Data Analysis
### Company Analysis
- Top companies by total layoffs
- Companies with repeated layoff events
- Top company by layoffs in each country

### Industry Analysis
- Industries with the highest layoffs
- Average layoffs by industry
- Industry diversification across countries

### Country Analysis
- Countries with the highest layoffs
- Countries affected across multiple industries

### Time-Based Analysis
- Monthly layoff trends
- Yearly layoff trends
- Rolling cumulative layoffs
- Peak layoff periods

### Funding Stage Analysis
- Layoffs by funding stage
- Frequency of layoffs across funding rounds

## 💡 Key Insights
- Identified the most impacted industries and countries.
- Discovered periods with significant layoff spikes.
- Highlighted companies with recurring workforce reductions.
- Analyzed the relationship between funding stages and layoffs.

## 🔍 SQL Concepts Used
- CTEs (Common Table Expressions)
- Window Functions
  - ROW_NUMBER()
  - RANK()
  - DENSE_RANK()
  - SUM() OVER()
- Aggregate Functions
- Subqueries
- Date Functions
- Joins

## 📂 Dataset
Layoffs dataset containing company, industry, country, funding stage, date, and layoff information.
